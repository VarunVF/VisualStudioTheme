# visualstudiolike README

Give VSCode a Visual Studio-style theme.

This theme tries to follow the style and colors in Visual Studio as closely as possible.
It is based on the Visual Studio Dark (C/C++) theme.

## Recommended Settings

To match Visual Studio appearance, add these settings to your `settings.json`.
These are user/editor settings and can't part of the theme.

1. Visual Studio default font
```json
"editor.fontFamily": "Cascadia Mono",
"editor.fontSize": 14
```

2. Bracket pair colorization (off in Visual Studio)
```json
"editor.bracketPairColorization.enabled": false
```

**Enjoy!**
